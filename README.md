# Foundly

Сервис объявлений о потерянных и найденных вещах в университетском кампусе.
Требования проекта описаны в [TZ.md](./TZ.md).

## Запуск

```bash
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Для запуска production-сборки выполни `npm run build`, затем `npm run start`.

## Страницы MVP

- `/` — лента с поиском и фильтрами.
- Интерфейс доступен на казахском, русском и английском языках.
- `/add` — форма создания объявления с проверкой полей и фото.
- `/item/[id]` — подробности, личный чат с автором, статус, удаление и жалоба.
- `/u/[username]` — профиль участника, доступный по никнейму.
- `/messages` — личные чаты, фильтры, отметки прочтения, вложения, сохранение и архивирование диалогов.
- `/register` и `/login` — регистрация и вход.

## Supabase

Добавьте `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` в `.env.local`.
Для уже настроенного проекта выполните `supabase/chat.sql` в Supabase SQL Editor:
скрипт настраивает защищённые чаты, отметки прочтения, вложения (до 5 файлов по 10 МБ,
JPG/PNG/WebP/PDF), состояния диалогов, блокировки, жалобы, Realtime и поле цены объявления.
Его можно выполнять повторно. При первоначальной настройке сначала выполните `supabase/schema.sql`.

На главной также показываются примеры объявлений; для них чат недоступен.
